# Commit Message Restrictions

Across the entire Cawlix project, all git commit messages must strictly follow these rules:

1. **Length**: Between 4 and 7 words (preferably 4 to 5 words).
2. **Formatting**: Plain words side-by-side. Never use prefixes, conventional commit tags, colons, or brackets (NO `feat:`, `fix:`, `feat(...)`, `fix(...)`, `[]`, `()`, or `:`).
3. **Language**: Simple, clear B1 English. Direct, accurate, and easy to understand without overly complex or decorative words.
4. **Content**: Directly and accurately describe the changes made.
